# Библиотека анимаций

Локальный проект для сопровождения библиотеки анимаций Kolesa Group с помощью ИИ-агентов.

Основная библиотека находится в [Figma](https://www.figma.com/design/J9tnSaZjfwU3stMUwrMalY/Библиотека-анимаций?node-id=244-1544). Корпоративный Google Drive хранит оригиналы высокого качества; ссылки в карточках ведут на файлы или папки.

Git хранит правила и документацию. Каталог связей, шаблоны и скрипты появятся на основе первого реального пополнения. Медиа и секреты в репозиторий не включаются.

- [Правила агента](AGENTS.md)
- [Процесс пополнения](docs/intake.md)

Пополнение запускается по запросу пользователя; готовые карточки добавляются сразу в основную библиотеку Figma. Доступ к корпоративному Drive проверяется при первой обработке конкретной ссылки.

Удалённый Git не подключён. Папка проекта синхронизируется с другими устройствами десктопным приложением Google Drive через аккаунт `basshybayev@kolesa.kz`. При переходе между устройствами нужно дождаться синхронизации и проверить состояние Git; избегать одновременного редактирования репозитория на нескольких устройствах.

Для действий с файлами на Google Drive используется Google Drive-плагин в Codex. Синхронизация папки не является Git remote; перенос истории `.git` отдельно не проверен. Git не откатывает внешние изменения в Figma или Drive. Веб-сервис и синхронизация содержимого библиотеки между Figma и будущим сервисом пока не реализуются.
