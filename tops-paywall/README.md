# Анимация машины на пейволле «Мощность рекламы» (Rive)

Файлы для разработки, на них ссылается артефакт «Анимация машины на пейволле «Мощность рекламы»». Последняя версия v4 от 26.11.2026: артборд 360 × 250, отступ от Dynamic Island.

- `tops_paywall_prod.riv`: Rive-файл, последняя версия (v4), 532 241 байт
- `tops-paywall.zip`: архив с `tops_paywall_prod.riv`, `handoff-rive.md`, `scene.rml`, `rive.yaml`
- `scene.rml`, `rive.yaml`: исходник Rive CLI (скрипты и ассеты хранятся в файле Rive)
- `handoff-rive.md`: спецификация для разработки
- `versions/v1` … `versions/v4`: все выгрузки файла по версиям (история в спеке, раздел 8)
